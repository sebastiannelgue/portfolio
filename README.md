## Proyectos

### 🍸 Sendero Gin — Landing page
`./sendero-gin`

Sitio web de marca y preventa para un gin artesanal argentino. Desarrollado desde cero, desplegado en producción con dominio propio.

- **Tecnologías:** HTML, CSS, JavaScript
- **Destacados:** diseño responsive, formulario de reservas, optimización SEO (sitemap, robots, JSON-LD, Open Graph) y despliegue en producción con dominio propio.
- **Sitio en vivo:** [senderogin.com.ar](https://senderogin.com.ar)

### 🏀 Liga de Baloncesto — Frontend
`./liga-baloncesto`

Interfaz de una aplicación de gestión de una liga de baloncesto juvenil: landing pública, clasificación automática, calendario, vista por equipo y panel de administración con login. Frontend desarrollado como parte de un trabajo académico grupal.

- **Tecnologías:** React, Vite, JavaScript, Axios
- **Destacados:** consumo de API REST, autenticación con JWT, ruteo con React Router y diseño responsive.
